# The Tay Fryer

A one-page website for a fictional fish & chip shop in Dundee, made as a portfolio piece.

- `index.html`: the whole site in one file (menu, opening hours, tap-to-call, map, dark mode).
- `portfolio/tay-fryer-showcase.jpg`: one image showing the site on desktop, in dark mode and on phones.

The Tay Fryer is not a real business. The name, address, phone number, prices and reviews are made up.

## How to switch on GitHub Pages

Use a web browser (Safari or Chrome), not the GitHub app.

1. Open https://github.com/dalesgordon-cmd/dg/settings/pages
2. Find the **Source** box, under the heading **Build and deployment**. Tap it and pick **Deploy from a branch**.
3. A new row appears with a button saying **None**. Tap it and pick **main**. Leave the folder on **/ (root)**.
4. Tap **Save**.

After a minute or two, refresh the page. A box at the top should say "Your site is live at https://dalesgordon-cmd.github.io/dg/".

The repository must stay public for this to work on a free GitHub account. Anything added to `main` will appear on the live site.
